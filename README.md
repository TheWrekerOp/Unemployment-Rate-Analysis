# Unemployment Rate Analysis by Region

**Author:** Wasif Raza  
**Project Type:** Exploratory Data Analysis and Hypothesis Testing  
**Contribution:** Individual

This project explores unemployment trends across U.S. states and World Bank regions, with a focus on regional differences and major economic events.

## Project files

- `UnemploymentRateAnalysis_TheWrekerOP.ipynb` — analysis notebook
- `us_states_unemployment_2000_2024_synthetic.csv` — U.S. state-level dataset
- `worldbank_regions_unemployment_2000_2024_synthetic.csv` — World Bank regional dataset
